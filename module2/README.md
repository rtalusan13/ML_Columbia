## Notes

Module 2 helped me understand linear regression better, especially how least squares works and its link to maximum likelihood when errors follow a Gaussian distribution. The explanations of regularization and ridge regression using the λ parameter were clear, and I now see how shrinking coefficients helps reduce overfitting by managing the bias-variance trade-off. I also found it interesting how ridge regression connects to MAP estimation, showing how frequentist and Bayesian approaches relate. Overall, the module made the theory behind these techniques much easier to understand and apply.
