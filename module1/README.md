# Module 1: Maximum Likelihood

## Module Content
This module is labeled "Maximum Likelihood". It features 11 mini-lectures on the following topics:

1. Introduction to Machine Learning
2. Data Modeling
3. Gaussian Distribution (Multivariate)
4. A Probabilistic Model
5. Maximum Likelihood Estimation
6. Multivariate Gaussian Example
7. Linear Regression
8. Linear Regression Example
9. Least Squares
10. Broadening Linear Regression
11. Geometry of Least Squares Regression

## Notes

Understanding basics of vector calculus is necessary to follow the derivation of closed formulae for Lecture 2: Linear Regression, Ridge Regression and Lasso Regression.
